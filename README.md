About the Project

The **Expense Tracker** is a simple and interactive web application that helps users track their daily expenses.

With this project, users can:
- ➕ Add new expenses with name and amount  
- ❌ Delete unwanted expenses  
- 📊 View total expenses in real time  
- 💾 Store data using browser **localStorage** (so data stays even after refresh)

---

Technologies Used

This project was built using:

- HTML → for structure  
- CSS → for styling and layout  
- JavaScript → for functionality and logic  
- localStorage → for saving data in browser  

---

How I Built It

I created this project step by step:
- First, I designed the basic structure using HTML  
- Then I styled it using CSS to make it look clean and simple  
- After that, I added JavaScript functionality to:
  - Add expenses dynamically  
  - Calculate total expenses  
  - Delete items from the list  
  - Save everything in localStorage
